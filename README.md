# 💬 TrinityChat - Web Messenger

Полнофункциональный веб-мессенджер в стиле Telegram.

## 🎯 Основные возможности

### 💬 Сообщения
- Real-time сообщения через WebSocket
- Поддержка файлов, фото, видео, архивов
- Информация об отправителе (никмейм + аватар)
- Время и дата отправления
- Копирование текста сообщений

### 👥 Управление группами
- Создание групп
- 🔨 **Кик** - выгнать из группы
- 🔇 **Мут** - запретить писать на N часов
- 🚫 **Бан** - заблокировать на N часов
- Просмотр списка участников

### 📺 Демонстрация экрана
- WebRTC-based screen sharing
- Fullscreen поддержка
- Видят только зрители (не презентер)
- Chrome, Yandex поддержка

### 🎨 Дизайн
- ✅ Светлая и тёмная тема
- ✅ Полная поддержка dark mode
- ✅ Без визуала (готово для интеграции дизайнера)

### 🔐 Безопасность
- Упрощённая регистрация (никмейм + пароль)
- JWT токены
- Логирование всех действий (AuditLog)
- Хеширование паролей (bcryptjs)

## 🚀 Быстрый старт

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Сервер: `http://localhost:3001`
Фронтенд: `http://localhost:3000`

## 📋 Требования

- Node.js 14+
- MongoDB 4.4+
- Windows 10 / Chrome / Yandex Browser

## 🔗 Мультиплеер

Если вы дали ссылку на сервер другому человеку:
1. Оба подключатся к одному серверу
2. Зарегистрируются под своими никмейнами
3. Смогут создавать чаты друг с другом
4. Всё синхронизируется в real-time

## 📝 Production

Для развёртывания:
1. Разверните на Heroku, Railway или VPS
2. Установите MongoDB Atlas
3. Настройте переменные окружения
4. Запустите серверы
